## What Is Egregor?

Egregor is a desktop application (also deployable on VPS) that orchestrates multiple AI models — Claude, Gemini, GPT, Grok, DeepSeek, Mistral, local models, and more — into a structured collaborative system called the **Consilium**. Instead of asking one AI and hoping for the best, you get a team of specialized AI agents with defined roles, checking each other's work, debating solutions, and synthesizing final answers that no single model could produce alone.

Think of it as the difference between consulting one doctor versus convening a panel of specialists from different fields. The panel wins — every time.

## The Core Architecture: Why It Beats Single Models

### Smart Resource Routing
Egregor analyzes every request before sending it and routes it to the right model:

| Request Complexity | Model Used | Cost |
|---|---|---|
| Simple (formatting, summary) | Free local model (Ollama) | $0 |
| Medium (analysis, writing) | Gemini Flash / DeepSeek | ¢ |
| Complex (architecture, strategy) | Claude + Gemini | $$ |
| Critical (final decision) | Full Consilium | $$$ |

**Result: 70-80% of requests run on free or ultra-cheap models. Premium AI fires only when truly needed.**

### Context Compression Engine
Instead of sending your entire conversation history with every request (which burns tokens), Egregor maintains a compressed Project Dossier — a living summary of all decisions, context, and progress. What would cost 100,000 tokens gets compressed to 5,000 without losing meaning. **10-20x cost reduction.**

### Semantic Cache
Similar questions get similar answers. Egregor stores question-answer pairs locally. If you ask something 95%+ similar to a past question, it retrieves the answer locally. **Zero tokens. Zero cost.**

## Unique Features No One Else Has

### 🧠 Soul Document
Egregor builds a living psychological portrait of how you think — your reasoning patterns, cognitive blind spots, preferred solutions, and decision-making style. Every AI in the Consilium uses this to communicate with you in your language, not generic AI language. Over time, the Consilium stops feeling like a tool and starts feeling like a team that truly knows you.

### ⚠️ Contradiction Machine
Egregor compares today's decisions against your entire history. If you decided one thing three months ago and now say the opposite, it stops and asks: *"On October 12th you decided differently. Did you change your mind consciously?"* No other tool does this. No other tool even tries.

### 🔮 Butterfly Effect Simulator
A 3D decision tree where Claude builds Timeline A, Gemini builds Timeline B, and DeepSeek attacks both as Devil's Advocate — projecting consequences 12-24 months forward. Navigate the branches in 3D space before committing to a real-world decision. See the ROI, the bottlenecks, the risks — before they happen.

### 🎯 Reverse Goal Engineering
Set a future milestone. Egregor works backward from that goal to today and gives you three specific, actionable micro-tasks every morning. You stop asking "what should I do?" and start executing. The Consilium automatically assembles if you get stuck — pushing you forward with code, text, or strategy as needed.

### 🌙 Night Mode
While you sleep, Egregor's local models analyze the day's work, identify unresolved contradictions, generate hypotheses, and prepare insights waiting on your desk in the morning. No cloud. No tokens spent. Completely free. You wake up to a team that already worked the night shift.

### 🎓 Newcomer Briefing
Add a new AI to your Consilium a month into a project? Egregor automatically generates a compressed Project Dossier — goals, all decisions made with dates, what failed and why, current architecture, open questions, and the roles of existing team members — and briefs the new AI in 10-15 seconds. It joins the team fully informed, ready to contribute immediately.

### 🔬 Confidence Meter
Every statement from every AI gets an automatic confidence rating (0-100%) and type label: Fact / Hypothesis / Opinion / Speculation. Color-coded in the UI. You never confuse a solid fact with an AI guess again. You see exactly how certain each participant is about everything they say.

### 🔭 Oracle + Prediction Tracking
AI models make explicit predictions about your projects with dates and confidence percentages. Egregor stores them and automatically checks accuracy at 3/6/12 months. Over time, you build real statistical data on which AI is most reliable for your specific type of work — and assign roles accordingly.

### 👁️ Vision Mode — Screen Analysis
**Click. Analyze. Fix.**

Stuck on a bug? One click captures your screen. The Consilium sees exactly what you see — the error, the code, the terminal output — and responds with a precise solution. No copy-pasting, no describing the problem. Egregor looks at it directly.

Privacy rules are hardcoded, not optional:
- Bank and payment pages: never captured
- Password fields: always excluded
- Personal messaging: blocked by default
- Only the active window, never the full screen
- One screenshot per click — no continuous surveillance

*"I got an error in my terminal → clicked Analyze → DeepSeek spotted the dependency conflict → Claude suggested the fix → Egregor executed the command."* Four steps that used to take 15 minutes, done in 30 seconds.

### 🦑 Tentacles — File System, Terminal & Browser Access
Egregor doesn't just think — it reaches out and acts.

**File System (with explicit permission):**
- Creates project folders and files on your desktop
- Reads existing code for context and analysis
- Saves outputs and results automatically
- Opens completed work in VS Code or any editor of your choice

**Terminal Access:**
- Installs dependencies (npm install, pip install)
- Runs scripts and build processes
- Executes Git commands (commit, push, pull, branch)
- Manages Docker containers and operations

**Browser Tentacles:**
- Searches documentation automatically during coding sessions
- Parses specific web pages for current data and APIs
- Checks your deployed site for live errors
- Pulls competitor data during strategy sessions

*"Build me a React project"* — Egregor doesn't write code into a chat box. It creates the folder, installs dependencies, scaffolds the structure, and opens it in your editor. You come back to a working project, not a wall of text to copy-paste.

Every file system, terminal, and browser action requires your explicit permission. A clear prompt appears before any action that touches your system. You control every level of access at all times.

Egregor doesn't look like any AI tool you've used before.
