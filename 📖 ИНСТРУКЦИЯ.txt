▓▓▓ 1. ЧТО ТАКОЕ ЭГРЕГОР ▓▓▓

Эгрегор — это десктопное приложение, которое запускает несколько ИИ-моделей (от Anthropic, Google, OpenAI, DeepSeek, Qwen, Meta, Mistral, xAI и других) в режиме коллективной работы. Они не просто отвечают параллельно — они дискутируют, критикуют друг друга, синтезируют общий вердикт, а главное: видят то, что один отдельный ИИ упустит.

В одиночке любой ИИ может ошибаться, уходить в галлюцинации, упускать детали. Когда же 4-7 ИИ работают вместе под управлением модератора, происходит "резонанс интеллектов" — каждая модель компенсирует слабые стороны других. Это особенно ценно для сложных задач: аудит смарт-контрактов, стратегические решения, критический code review, написание книг, поиск нестандартных идей.

Эгрегор работает локально на твоём компьютере (Windows, macOS, Linux) и подключается к моделям через единый API — OpenRouter.ai.


▓▓▓ 2. ФИЛОСОФИЯ И АРХИТЕКТУРА ▓▓▓

Главная идея — не "сравнить мнения 5 ИИ", а получить КАЧЕСТВЕННО НОВЫЙ ответ, рождённый из коллективной дискуссии.

Архитектурные слои:
• Модели ИИ — мозг системы (Claude, Gemini, GPT, DeepSeek, и т.д.)
• Роли — у каждого ИИ своя функция (разработчик, security-аудитор, креативщик, фактчекер...)
• Модератор — главный ИИ, синтезирующий ответы остальных
• Расширения контекста — Soul Document, Big Text, Project Dossier, Big Project Map
• Защитные механизмы — Anti-Groupthink, Red Team, Карта уверенности

Платишь только за реально использованные токены через OpenRouter — обычно центы за запрос. Многие модели полностью бесплатны.


▓▓▓ 3. ПЕРВЫЙ ЗАПУСК ▓▓▓

ШАГ 1. Получи API-ключ OpenRouter
→ Открой https://openrouter.ai (кнопка 🔗 OpenRouter в шапке)
→ Зарегистрируйся (gmail или почта)
→ Раздел "Keys" → "Create Key" → скопируй

ШАГ 2. Вставь ключ в Эгрегор
→ Кнопка 🔴 Нет ключа справа вверху
→ Вставь ключ → Сохранить
→ Должно стать 🟢 Основной

ШАГ 3. Заполни "Мой контекст" (5 минут — окупится сторицей)
→ Кнопка 📝 Мой контекст в шапке
→ Опиши кто ты, чем занимаешься, какие проекты
→ Сохрани
→ Теперь все ИИ всегда знают контекст и адаптируют ответы

ШАГ 4. Выбери пресет или собери свой консилиум
→ В шапке: "Универсальный 🌐", "Разработка кода 💻", "Креативный 🎨", "Стратегия 🚀"
→ Или "Ещё пресеты ▾" — 25 готовых наборов
→ Можно собрать свой: кнопка "+" в левой панели

ШАГ 5. Задай первый вопрос
→ Просто пиши в поле снизу
→ Прикрепляй файлы кнопкой 📎 или drag-and-drop

▓▓▓ 4. API-КЛЮЧИ ▓▓▓

══ 4.1 ЧТО ТАКОЕ OPENROUTER ══

OpenRouter.ai — это единый API-шлюз к 300+ моделям ИИ от всех ведущих провайдеров. Один ключ — доступ ко всему. Цены — те же что у оригинальных провайдеров (или дешевле через бесплатных провайдеров на OpenRouter).

Вместо того чтобы иметь 5 разных аккаунтов (Anthropic, OpenAI, Google, и т.д.) — у тебя один ключ OpenRouter, и ты используешь любые модели одним движением.

══ 4.2 ПОЛУЧЕНИЕ КЛЮЧА ══

1. Открой openrouter.ai (или кнопку 🔗 OpenRouter в Эгрегоре)
2. Зарегистрируйся
3. Пополни счёт (минимум $5 — хватит надолго, или используй только 🆓 модели)
4. Раздел Keys → Create Key
5. Скопируй ключ (он начинается с sk-or-v1-...)
6. Вставь в Эгрегор: кнопка 🔴 Нет ключа → Сохранить

══ 4.3 БЕСПЛАТНЫЕ 🆓 МОДЕЛИ ══

OpenRouter предоставляет ряд моделей бесплатно (с ограничениями на rate-limits, но для большинства задач этого хватает). В каталоге Эгрегора они отмечены 🆓:

• DeepSeek R1 🆓 — глубоко рассуждает, отлично для анализа кода
• DeepSeek V3 🆓 — общего назначения, хорошее качество
• Qwen3 Coder 480B 🆓 — топовый кодер
• Qwen 3 235B 🆓 — общий
• Llama 4 Maverick 🆓 — от Meta
• Llama 4 Scout 🆓 — лёгкая
• Gemma 3 🆓 — от Google
• Nemotron 3 Super 🆓 — от Nvidia

Бесплатные модели НЕ дают качества Claude Opus или GPT-4, но для черновиков, простых вопросов, первого прохода аудита — отлично экономят.

══ 4.4 ХИТРОСТЬ: ДВА КЛЮЧА ДЛЯ ЭКОНОМИИ ══

Один из самых полезных приёмов:

• Ключ "Основной" — твой основной аккаунт с балансом
• Ключ "Бесплатный" — отдельный аккаунт ТОЛЬКО для 🆓 моделей

Так бесплатные модели работают через лимиты второго аккаунта, не конкурируя с твоим основным. Удваивает количество бесплатных запросов в день.

Создай два аккаунта OpenRouter на разные email-адреса. В Эгрегоре кнопка 🟢 → + Добавить ключ → назови "Бесплатный".

══ 4.5 ПЕРЕКЛЮЧЕНИЕ МЕЖДУ КЛЮЧАМИ ══

Кнопка 🟢 в шапке открывает менеджер ключей. Клик по ключу делает его активным — все следующие запросы пойдут через него. Удобно переключаться когда лимит на одном исчерпан.

══ 5.3 БЕСПЛАТНЫЕ МОДЕЛИ ══

Бесплатные модели на OpenRouter имеют rate-limits (~20 запросов в минуту, 200 в день на ключ). Этого хватает для большинства задач. Стратегия:

1. Используй 🆓 модели как ПЕРВЫЙ ЭШЕЛОН — для черновых ответов
2. Если результат не удовлетворил — переключись на платные
3. Используй два ключа (см. 4.4) чтобы удвоить дневной лимит

🆓 модели идеально работают в:
• Эконом-режиме (быстрые короткие ответы)
• Параллельных консилиумах (где можно поставить 3-4 бесплатные модели + одну платную как модератора)
• Code Review pipeline (Reasoning + Alternative — бесплатные, Security + Final — платные Claude)

══ 5.4 ПРОИЗВОЛЬНЫЕ МОДЕЛИ OPENROUTER ══

Каталог Эгрегора обновляется при выпуске новых версий. Но если OpenRouter добавил новую модель которой ещё нет в каталоге — её можно использовать вручную:

1. В каталоге Эгрегора (или в редакторе Pipeline) выбери "＋ Ввести ID любой модели OpenRouter..."
2. Введи ID вида provider/model-name (например anthropic/claude-opus-5)
3. Эгрегор сохранит её и начнёт использовать

Найти ID любой модели можно на openrouter.ai/models (кнопка 🔗 OpenRouter в шапке).


▓▓▓ 6. АКТИВНЫЕ ИИ ▓▓▓

══ 6.1 ДОБАВЛЕНИЕ И УДАЛЕНИЕ ══

Слева — панель активных ИИ (то, что сейчас участвует в консилиуме).

Добавить:
• Кнопка "+" внизу панели → выбери из каталога
• Или загрузи готовый пресет в шапке

Удалить:
• Кликни на ИИ → справа кнопка 🗑

Временно отключить (не удаляя):
• Кликни на ИИ → тумблер "Активен"

В консилиуме может быть от 1 до 10 ИИ. Оптимально 3-5 для качества и скорости.

══ 6.2 РОЛИ — ЧТО ОНИ ОЗНАЧАЮТ ══

У каждого ИИ есть РОЛЬ — это его профессиональная маска. Роль влияет на:
• Стиль ответа (творческий / технический / критический)
• Что ИИ ищет в вопросе
• Как ИИ ведёт себя в дискуссии с другими

Основные роли:
👑 Модератор (mod) — синтезирует ответы остальных, выдаёт финальный вердикт
💻 Разработчик (dev) — глубокий анализ кода, архитектура
🛡️ Безопасник (security) — поиск уязвимостей, аудит
🎨 Креативщик (creative) — нестандартные идеи, переосмысление
📋 Аудитор (auditor) — критический разбор, поиск противоречий
🔍 Фактчекер (factcheck) — точность информации, источники
💼 Бизнес-аналитик (business) — рыночный взгляд, ROI
🎭 Адвокат дьявола (devil) — атака на консенсус
👁️ Наблюдатель (observer) — нейтральная позиция

Роль меняется кликом по ИИ → выпадающий список ролей.

══ 6.3 МОДЕРАТОР — ГЛАВНЫЙ СИНТЕЗАТОР ══

Один из ИИ всегда выделен значком 👑 — это МОДЕРАТОР. Он:
• Получает ответы всех остальных
• Анализирует противоречия и согласие
• Выдаёт финальный синтез
• В режиме Code Review — пишет финальный вердикт
• В Anti-Groupthink — следит за соблюдением правил

Назначить модератора: клик на ИИ → роль "👑 Модератор". Только один модератор за раз.

Рекомендация: модератором ставь самую сильную модель — Claude Opus 4.7 или Sonnet 4.6 для важных задач.

▓▓▓ 7. ЧЕТЫРЕ ОСНОВНЫХ РЕЖИМА ▓▓▓

══ 7.1 🤖 ОДИНОЧНЫЙ РЕЖИМ ══

Активируется автоматически когда в консилиуме только один ИИ. Работает как обычный ChatGPT-style чат — один ИИ, один ответ. Подходит для:
• Простых вопросов
• Когда не нужна дискуссия
• Когда экономишь токены

══ 7.2 📊 СОВОКУПНЫЙ АНАЛИЗ ══

Тумблер в toolbar над полем ввода. Один раунд: все ИИ отвечают параллельно на твой вопрос, модератор делает финальный синтез.

Используй для:
• Сравнения мнений разных моделей
• Быстрых вопросов где нужна разносторонность
• Когда не нужна сама дискуссия, нужен сводный взгляд

Дешевле и быстрее живого консилиума.

══ 7.3 🏛️ ЖИВОЙ КОНСИЛИУМ ══

Главный режим Эгрегора. Несколько раундов дискуссии:

Раунд 1: Каждый ИИ отвечает на твой вопрос со своей ролью.
Раунд 2: Каждый ИИ читает что сказали остальные, критикует, дополняет, соглашается.
Раунд 3 (опционально): Поиск консенсуса.
Финал: Модератор синтезирует всё в финальный вердикт.

Идеально для:
• Сложных стратегических решений
• Архитектурных задач
• Творческих проектов
• Любых ситуаций где важна полнота анализа

══ 7.4 💻 КОНВЕЙЕР КОД-РЕВЬЮ ══

Специальный режим для аудита кода (см. ГЛАВА XI, раздел 18). Это не дискуссия параллельно, а строгий последовательный pipeline из 5 шагов где каждый ИИ — специалист в своей области:

1. ✍️ Reasoning (разработчик) — глубокий анализ
2. 🛡️ Security (аудитор безопасности) — поиск уязвимостей
3. 🔧 Alternative (креативщик) — переписать проблемные места
4. ⚖️ Comparison (аналитик) — сравнить варианты
5. 👑 Final Verdict (модератор) — итоговые рекомендации

Каждый шаг видит работу предыдущих. Получаешь профессиональный аудит уровня CertiK за центы вместо тысяч долларов.

══ 7.5 📖 БОЛЬШОЙ ТЕКСТ (РАСШИРЕНИЕ) ══

Это не режим, а РАСШИРЕНИЕ контекста. Активируется тумблером 📖 Большой текст в toolbar. Подробно — в ГЛАВЕ X, разделе 15.

Суть: когда нужно работать с очень большим документом (>40000 символов, ~100+ страниц книги), Эгрегор:
1. Один ИИ (Gemini 2.0 Flash по умолчанию, 1M контекст) читает документ целиком
2. Создаёт структурированное резюме (~5000 токенов)
3. Остальные ИИ работают с резюме

Огромная экономия. Подробнее — в главе про большой текст.

▓▓▓ 8. ТУМБЛЕРЫ КАЧЕСТВА И ЭКОНОМИИ ▓▓▓

В шапке справа — ряд тумблеров и кнопок управления:

══ 8.1 ПО ОЧЕРЕДИ ══

По умолчанию все ИИ в раунде отвечают ПАРАЛЛЕЛЬНО — быстро, но нагружает процессор и память. Если компьютер слабый или ты хочешь увидеть как каждый ИИ "думает" — включи "По очереди". ИИ будут отвечать строго один за другим.

══ 8.2 💰 ЭКОНОМ-РЕЖИМ ══

Включён → консилиум становится короче и дешевле:
• 2 раунда фикс (вместо 3-4)
• Участники пишут ~150 слов на ответ (вместо 400+)
• Модератор пишет ~500 слов вместо 1500+
• Экономия токенов ~75%

Полезно для простых вопросов где не нужен полный анализ. Несовместим с Anti-Groupthink (они оба меняют структуру дискуссии).

══ 8.3 🛡️ ANTI-GROUPTHINK ══

Главная защита от группового мышления — когда ИИ начинают повторять друг друга из-за того что видят одни и те же ответы.

Включает два механизма:

🎭 Слепой первый раунд — все ИИ отвечают НЕ ВИДЯ роли. Они не знают что один — security, другой — креативщик. Получают чистые независимые мнения, без подгонки под роль.

⚔️ Ротационный адвокат дьявола — на каждом раунде один из участников ВРЕМЕННО становится атакующим. Его задача — найти слабые места в общем направлении. Роль "адвоката" меняется по кругу.

⚠️ Стоит примерно +30% токенов. Несовместим с Эконом-режимом.

Включай для:
• Стратегических решений с высокими ставками
• Когда нужно избежать "согласия из вежливости"
• Аудита безопасности
• Любых задач где консенсус кажется подозрительно быстрым

══ 8.4 🛡️ RED TEAM ══

Подопция Anti-Groupthink (появляется только когда AG включён). Финальный раунд атаки на сложившийся консенсус.

Перед вердиктом модератора участники ещё раз пройдут по консенсусу и попытаются его разрушить: найти риски, упущения, скрытые допущения.

⚠️ Добавляет ещё ~15% токенов.

Включай когда:
• Финальное решение очень критично (миллионы вложений, безопасность смарт-контракта)
• Хочешь избежать "красивого но опасного" вердикта

══ 8.5 📊 КАРТА УВЕРЕННОСТИ ══

Не тумблер, а функция. После каждого финального вердикта модератор оценивает уверенность консилиума по шкале 1-5:

🟢 5/5 — полное согласие — все ИИ пришли к единому мнению без споров
🟢 4/5 — сильное согласие — мнения близки, мелкие расхождения
🟡 3/5 — умеренное согласие — есть существенные различия, но общая линия есть
🟠 2/5 — слабое согласие — серьёзные разногласия, вердикт компромиссный
🔴 1/5 — нет согласия — мнения противоположны, единого вывода нет

Бейдж появляется в заголовке финального ответа. Это сигнал тебе: насколько можно доверять вердикту.

Если карта показывает 🔴 1/5 или 🟠 2/5 — обычно стоит:
• Перечитать раунды и понять в чём разногласие
• Уточнить вопрос
• Запустить с Anti-Groupthink + Red Team
• Привлечь экспертов

══ 8.6 🔗 OPENROUTER ══

Кнопка для быстрого перехода на openrouter.ai/models — каталог всех 300+ моделей. Полезно когда:
• Ищешь модель которой нет в каталоге Эгрегора
• Хочешь посмотреть актуальные цены
• Хочешь сравнить характеристики

▓▓▓ 9. 📝 МОЙ КОНТЕКСТ (SOUL DOCUMENT) ▓▓▓

══ 9.1 ЧТО ЭТО И ЗАЧЕМ ══

Soul Document (или "Мой контекст") — это твоя визитка для всех ИИ. Один раз заполнил — и любой ИИ в любом проекте знает кто ты, чем занимаешься, какой у тебя бэкграунд.

Без него ИИ каждый раз отвечает в вакууме — общие советы для "среднего пользователя". С ним — конкретные советы под твою ситуацию.

══ 9.2 КАК ЗАПОЛНИТЬ ══

Кнопка 📝 Мой контекст в шапке.

Полезно указать:
• Имя и сфера деятельности
• Уровень экспертизы (новичок / профи / эксперт в чём-то)
• Активные проекты (краткое описание)
• Любимые технологии, языки программирования
• Стиль общения (формальный, неформальный, прямолинейный)
• Любые личные особенности которые помогут адаптировать ответы

Длина — от 200 до 2000 слов. Слишком короткий — нет смысла, слишком длинный — раздует контекст и стоимость токенов.

══ 9.3 КОГДА ПРИМЕНЯЕТСЯ ══

Soul Document автоматически прикрепляется к КАЖДОМУ системному промпту любого ИИ в Эгрегоре. Ты ничего не делаешь — он работает.

Когда обновлять:
• Сменил работу или проект
• Получил новый опыт (выучил Solidity, освоил трейдинг)
• Поменялись интересы

Кнопка показывает 📝 Контекст ✓ когда документ заполнен.

▓▓▓ 10. ТИПЫ ФАЙЛОВ ▓▓▓

══ 10.1 ТЕКСТОВЫЕ И КОДОВЫЕ ══

Поддерживаются все основные форматы:
• Документация — .md, .txt, .html, .xml, .json, .yaml, .yml, .toml, .ini
• JavaScript / TypeScript — .js, .ts, .jsx, .tsx, .mjs, .cjs
• Python — .py
• Solidity — .sol
• Rust — .rs
• Go — .go
• C/C++ — .c, .cpp, .h, .hpp
• Java / Kotlin / Swift — .java, .kt, .swift
• PHP / Ruby / Lua / Dart — .php, .rb, .lua, .dart
• Shell / SQL / Config — .sh, .bat, .ps1, .sql, .conf
• Веб-фреймворки — .vue, .svelte, .astro
• Драйверы Linux — .inf, .dts, .dtsi, .ld, .mod

Размер до 500 KB на файл, до 12000 символов читается в контекст (для одиночного файла).

══ 10.2 PDF И ДОКУМЕНТЫ OFFICE ══

PDF поддерживаются полностью через библиотеку pdf-parse. Просто прикрепи — Эгрегор извлечёт текст и передаст ИИ.

Документы Word (.docx) и PowerPoint (.pptx) — частично, через текстовое извлечение.

══ 10.3 ИЗОБРАЖЕНИЯ ══

Поддерживаются .png, .jpg, .jpeg, .gif, .webp. ИИ, поддерживающие vision (Claude, GPT-4o, Gemini), будут анализировать изображения. Остальные модели увидят только метаданные.

══ 10.4 КНИГИ (EPUB, FB2, RTF) ══

Эгрегор умеет читать книжные форматы:
• EPUB — через adm-zip распаковывается и собирается текст
• FB2 — парсинг XML
• RTF — извлечение текста через regex

Для больших книг автоматически предлагается режим 📖 Большой текст (см. раздел 15).

══ 10.5 АРХИВЫ — ZIP, RAR, 7Z, TAR, GZ ══

Через node-7z + 7zip-bin поддерживаются все основные форматы:
• .zip — стандартный архив
• .rar — формат WinRAR
• .7z — высокая компрессия
• .tar, .gz, .tgz — Unix-архивы
• .bz2, .tbz, .tbz2 — bzip2
• .xz — LZMA2

Вложенные архивы — до 3 уровней рекурсии. Лимит файлов в архиве — 200 (защита от архив-бомб).

Когда в архиве есть код — Эгрегор может автоматически предложить включить Big Project Mode для совокупного анализа (см. раздел 20).

══ 10.6 DRAG-AND-DROP И КНОПКА 📎 ══

Два способа прикрепить файлы:

1. КНОПКА 📎 рядом с полем ввода — открывает стандартный диалог выбора файлов.

2. DRAG-AND-DROP — перетащи файлы прямо в окно Эгрегора. Поддерживаются папки целиком (Эгрегор рекурсивно соберёт файлы).

⚠️ ВАЖНО для Electron 32+: при drag-and-drop архивов на Windows нужно использовать кнопку 📎, не drag (там бага с пустыми путями файлов).

Лимит: до 15 файлов одновременно прикреплено. Можно убрать ✕.

▓▓▓ 16. 📚 CONTEXT COMPRESSION ENGINE ▓▓▓

══ 16.1 PROJECT DOSSIER — ЧТО ЭТО ══

Когда чат с консилиумом разрастается до сотен сообщений, контекст становится огромным — каждый новый запрос тащит за собой всю историю. Стоимость токенов растёт лавинообразно.

Project Dossier решает это. Это компактное резюме всего вашего разговора в проекте — основные темы, решения, договорённости, открытые вопросы. Создаётся одним ИИ (хранителем) и подставляется в контекст вместо полной истории.

══ 16.2 КОГДА ВКЛЮЧАТЬ ══

• Длинные проекты (30+ сообщений в одной теме)
• Когда замечаешь что ответы стали дороже
• При работе над книгой или продолжительной задаче

Эгрегор сам предложит включить при достижении 30 сообщений в проекте.

══ 16.3 ХРАНИТЕЛЬ ДОСЬЕ ══

По умолчанию досье ведёт Gemini 2.0 Flash (1M контекст, быстрый, дешёвый). Можно сменить в настройках 📚 Сжатие → ⚙️.

Структура досье (5 разделов):
1. Главные темы обсуждения
2. Принятые решения и договорённости
3. Открытые вопросы
4. Ключевые факты и контекст
5. Динамика и направление дальнейшего движения

══ 16.4 ТРИГГЕРЫ ПЕРЕСБОРКИ ══

Досье обновляется автоматически:
• Каждые 6 новых сообщений
• Или когда контекст превышает 50000 токенов

Также можно пересобрать вручную: панель 📚 Сжатие → Пересобрать.

══ 16.5 ЭКОНОМИЯ ТОКЕНОВ ══

Реальная экономия:
• До включения: контекст 100к токенов → каждый запрос дорогой
• С Compression: контекст 5к токенов резюме → запросы дешёвые
• Экономия 10-20× на длинных проектах


▓▓▓ 17. 🧠 SEMANTIC CACHE ▓▓▓

══ 17.1 ПРИНЦИП РАБОТЫ ══

Если ты задал тот же или похожий по смыслу вопрос в прошлом — Эгрегор может вернуть тот же ответ БЕЗ обращения к API. Нулевая стоимость, моментальный ответ.

══ 17.2 EMBEDDINGS И COSINE SIMILARITY ══

Каждый вопрос превращается в вектор из ~1500 чисел через модель embeddings (по умолчанию openai/text-embedding-3-small — копейки за запрос). Похожие по смыслу вопросы имеют близкие векторы.

При новом вопросе сравниваем его вектор с сохранёнными через cosine similarity (число от 0 до 1).

══ 17.3 ПОРОГИ СОВПАДЕНИЯ ══

• >95% — молча возвращаем кешированный ответ 🔁
• 85-94% — спрашиваем "Похожий вопрос: ... — использовать прошлый ответ?"
• <85% — обычный запрос к API

══ 17.4 КОГДА КЕШ НЕ ИСПОЛЬЗУЕТСЯ ══

Кеш ОТКЛЮЧАЕТСЯ для:
• Запросов с прикреплёнными файлами (там всегда новый контекст)
• Запросов с временными словами: "сегодня", "сейчас", "новости", "курс", "погода", "актуальн", "недавн" — на русском и английском

══ 17.5 СТАТИСТИКА И СБРОС ══

Кнопка 🧠 Кеш ✓ показывает счётчик попаданий. Клик 🔁 рядом — статистика:
• Попаданий за всё время
• Запросов в API
• Сэкономлено токенов

Сброс кеша: ⚙️ → Очистить кеш.

Хранение — per-project (у каждого проекта свой кеш) или глобальное (через переключатель в настройках).

TTL записи — 30 дней. Лимит — 500 записей на проект.

▓▓▓ 18. 💻 КОНВЕЙЕР КОД-РЕВЬЮ ▓▓▓

══ 18.1 КОНЦЕПЦИЯ ПОСЛЕДОВАТЕЛЬНОГО PIPELINE ══

В обычном консилиуме ИИ работают ПАРАЛЛЕЛЬНО — каждый со своей ролью отвечает на один вопрос. Но для кода нужно иначе: код-ревью требует последовательной цепочки специалистов как в реальной команде разработки.

Конвейер код-ревью — это четвёртый режим работы (кнопка 💻 Код-ревью в toolbar). 5 ИИ работают строго по очереди, каждый видит результаты предыдущих.

══ 18.2 ПЯТЬ ШАГОВ КОНВЕЙЕРА ══

ШАГ 1. ✍️ REASONING — глубокий анализ
Что делает код? Архитектура. Допущения. Логические проблемы. Производительность.

ШАГ 2. 🛡️ SECURITY — поиск уязвимостей
Smart contracts: reentrancy, integer overflow, access control, msg.sender, front-running, oracle manipulation. Web: SQL injection, XSS, CSRF. Общее: race conditions, секреты в коде, weak crypto.

ШАГ 3. 🔧 ALTERNATIVE — альтернативная реализация
Переписывание проблемных мест. Другая архитектура. Конкретный код, не общие слова.

ШАГ 4. ⚖️ COMPARISON — сравнение
Где альтернатива лучше / хуже. Что критично / вкусовщина. Компромиссы. Беспристрастный вердикт.

ШАГ 5. 👑 FINAL VERDICT — итоговые рекомендации
Структурированный отчёт:
🔴 Критичные изменения (обязательно)
🟡 Рекомендуемые (стоит сделать)
🟢 Опциональные (по желанию)
✅ Что оставить как есть
💡 Финальный код

С картой уверенности 1-5.

══ 18.3 РАСПРЕДЕЛЕНИЕ МОДЕЛЕЙ ПО РОЛЯМ ══

Идеальный состав для аудита смарт-контракта:

ШАГ 1 → DeepSeek R1 🆓 (думает глубоко)
ШАГ 2 → Claude Sonnet 4.6 (топ по security)
ШАГ 3 → Qwen3 Coder 480B 🆓 (топовый кодер)
ШАГ 4 → GPT-4.1 (объективный аналитик)
ШАГ 5 → Claude Opus 4.7 (финальный судья)

3 из 5 моделей — бесплатные. Общая стоимость аудита проекта ~$0.30-0.50 против $5000-50000 у CertiK.

▓▓▓ 19. ⚙️ РЕДАКТОР PIPELINE ▓▓▓

══ 19.1 АВТО-РЕЖИМ VS РУЧНАЯ НАСТРОЙКА ══

Кнопка ⚙️ рядом с кнопкой 💻 Код-ревью открывает настройки конвейера. Два режима:

🤖 АВТО-РЕЖИМ (по умолчанию)
Эгрегор сам выбирает ИИ из активного консилиума по их ролям. Подходит когда у тебя сбалансированный консилиум где есть dev, security, creative, auditor роли.

✋ РУЧНАЯ НАСТРОЙКА
Ты явно назначаешь конкретные модели на каждый шаг. Дает полный контроль — особенно важно для аудита где нужны самые сильные модели.

══ 19.2 ВЫБОР МОДЕЛЕЙ ДЛЯ КАЖДОГО ШАГА ══

В ручном режиме каждый шаг имеет dropdown с тремя группами:

🟢 Активные в консилиуме — ИИ из текущего состава
🤖 Anthropic / 🔵 Google / 🟢 OpenAI / ... — полный каталог Эгрегора
⚡ OpenRouter — кнопка ввода любого ID модели вручную

══ 19.3 ПОЛНЫЙ КАТАЛОГ + ПРОИЗВОЛЬНЫЕ МОДЕЛИ OPENROUTER ══

Опция "＋ Ввести ID любой модели OpenRouter..." открывает поле ввода. Введи любой ID (например anthropic/claude-opus-5 или новую модель которой ещё нет в каталоге) — она будет использована.

Рядом — кнопка 🔗 OpenRouter, открывающая каталог openrouter.ai/models в браузере для поиска новых моделей.

══ 19.4 ВКЛЮЧЕНИЕ/ВЫКЛЮЧЕНИЕ ШАГОВ ══

Чекбокс слева от каждого шага. Если выключить шаг — он пропускается в pipeline (например, если хочешь быстрое ревью без шага сравнения).

⚠️ Финальный шаг 👑 нельзя отключить — он обязателен (помечен 🔒).

══ 19.5 СОХРАНЕНИЕ НАСТРОЕК ══

Настройки конвейера (mode + список шагов с моделями + чекбоксы) сохраняются в localStorage. При перезапуске Эгрегора восстанавливаются.

Кнопка "🔄 Сбросить" возвращает дефолт (auto-режим, все шаги включены).


▓▓▓ 20. 📦 BIG PROJECT MODE — АНАЛИЗ КОДОВОЙ БАЗЫ ▓▓▓

══ 20.1 ЗАЧЕМ ЭТО НУЖНО ══

Обычный режим работы с архивом обрезает каждый файл до 12000 символов — для аудита большого проекта это профанация. Реальный аудит смарт-контракта требует ВСЕХ файлов целиком, понимания связей между ними, отслеживания цепочек вызовов.

Big Project Mode решает это. Когда включён:
✅ Все файлы читаются ЦЕЛИКОМ (без обрезки)
✅ Парсинг import — строится граф зависимостей
✅ Хранитель пишет "Карту Проекта" — общий обзор архитектуры
✅ Чанкование по функциям, embeddings всех функций
✅ RAG-поиск релевантного кода при каждом запросе
✅ Интеграция с конвейером код-ревью — каждый шаг получает свой релевантный код

Идеально для аудита смарт-контрактов из нескольких файлов или code review целого модуля.

══ 20.2 ЭТАП 1: ИНДЕКСАЦИЯ И КАРТА ПРОЕКТА ══

При включении 📦 Big Project Mode и прикреплении архива с кодом:

1. РАСПАКОВКА — архив раскрывается в постоянную папку %TEMP%/egregor_big_projects/{projectId}/src/
2. ЧТЕНИЕ — все файлы кода читаются целиком (лимит на файл 2 MB, на проект — 50 MB и 500 файлов)
3. ПАРСИНГ IMPORT — для каждого файла находятся импорты:
   • Solidity: import "./Vault.sol"
   • JS/TS: import X from "./Y"
   • Python: from X import Y
   • Rust: use crate::X
   • Go: import "X"
4. ГРАФ ЗАВИСИМОСТЕЙ — строится прямой граф (что от чего зависит) и обратный (кто использует данный файл)
5. КАРТА ПРОЕКТА — хранитель (Gemini 2.0 Flash по умолчанию) пишет 7-разделное резюме:
   1. Тип проекта и назначение
   2. Архитектура
   3. Карта файлов (каждый файл с описанием)
   4. Граф связей в текстовом виде
   5. Подозрительные места и риски (предварительный обзор)
   6. Ключевые функции
   7. Рекомендации по аудиту

Эта Карта подставляется в системный промпт ВСЕХ ИИ.

══ 20.3 ЭТАП 2: ЧАНКОВАНИЕ И EMBEDDINGS (RAG) ══

После Карты Проекта:

1. ЧАНКОВАНИЕ — каждый файл разбивается на функции/методы/контракты. Для Solidity: function, modifier, constructor, contract, library, interface. Для JS/TS: function, class, методы, arrow-функции. Для Python: def, class. Для Rust: fn, impl, struct, enum, trait. Для Go: func, type struct, type interface.

2. EMBEDDINGS — для каждого чанка через OpenRouter генерируется вектор (по умолчанию openai/text-embedding-3-small). Прогресс показывается в панели Big Project. Стоимость ~$0.0001 за чанк, на проект из 50 функций ~$0.005.

3. RAG-ПОИСК — при каждом твоём запросе:
   • Получаем embedding запроса
   • Считаем cosine similarity со всеми чанками
   • Берём топ-8 самых релевантных
   • Дополнительно по графу зависимостей добавляем связанные функции
   • Контекст автоматически приклеивается к запросу

══ 20.4 ЭТАП 3: ИНТЕГРАЦИЯ С КОД-РЕВЬЮ ══

В режиме 💻 Код-ревью когда активен Big Project Mode — каждый шаг конвейера делает СВОЙ RAG-запрос по своей специализации:

ШАГ 1 (Reasoning) → ищет точки входа, публичные функции, конструкторы
ШАГ 2 (Security) → ищет external calls, msg.sender, transfer, delegatecall, modifiers, onlyOwner
ШАГ 3 (Alternative) → ищет критические пути, core business logic
ШАГ 4 (Comparison) → работает с накопленными результатами
ШАГ 5 (Final) → получает суммарный список всех функций которые видели предыдущие шаги

Это превращает Эгрегор в полноценный аудитор уровня CertiK для проектов до 50000 строк кода.

══ 20.5 ПОДДЕРЖИВАЕМЫЕ ЯЗЫКИ ══

ПАРСИНГ IMPORT:

• Python, Rust, Go

ЧАНКОВАНИЕ ПО ФУНКЦИЯМ:
• Те же языки + поддержка через regex шаблоны

ЧТЕНИЕ ФАЙЛОВ (без чанкования):

• PHP, Ruby, Lua, Shell, SQL
• Vue, Svelte, Astro

• Документация (MD, TXT, HTML, CSS, SCSS)

══ 20.6 ЛИМИТЫ И ОГРАНИЧЕНИЯ ══

• Файлов в проекте — 500
• Размер одного файла — 2 MB
• Общий размер проекта — 50 MB
• Вложенность архивов — 3 уровня

══ 20.7 СОХРАНЕНИЕ МЕЖДУ СЕССИЯМИ ══

После индексации в папке %TEMP%/egregor_big_projects/{projectId}/ хранится:

• index.json — метаданные (граф, чанки без content)
• embeddings.json — векторы всех чанков

При переключении на проект Эгрегор:
1. Восстанавливает индекс из index.json
2. Подгружает embeddings.json в память
3. Готов отвечать с RAG моментально

Очистка: кнопка 🗑 в панели Big Project удаляет всё.

▓▓▓ 23. FAQ И УСТРАНЕНИЕ ОШИБОК ▓▓▓

Ошибка "Insufficient credits"
→ Закончился баланс OpenRouter. Пополни или переключись на 🆓 модели.

Ошибка "Rate limit exceeded"
→ Превышен лимит запросов в минуту. Подожди немного или переключи ключ.

Ошибка "Model not found"
→ Опечатка в ID модели или модель удалена. Проверь на openrouter.ai/models.

Эгрегор долго запускается
→ Первый запуск 5-7 сек — нормально (загрузка React DevTools). После сборки в .exe будет 2-3 сек.

Поле ввода "замирает" при прикреплении большого архива
→ Идёт индексация Big Project. Подожди ~30 секунд — Эгрегор работает.

Не видно кнопок в шапке
→ Слишком узкое окно. Расширь или используй адаптивный режим (кнопки переносятся на вторую строку).

Бесплатные модели не работают
→ Бесплатные модели имеют лимиты ~20 запросов/мин, ~200/день на ключ. Используй два ключа (см. 4.4).

Чат стал отвечать медленно/дорого
→ Контекст разросся. Включи 📚 Сжатие или начни новый проект.

Big Project не индексируется
→ Проверь что архив содержит файлы кода (поддерживаемые расширения). Если в архиве много js/ts — возможно превышен лимит файлов (500) или размера (50 MB).

PDF не парсится
→ Проверь что pdf-parse установлен: npm install pdf-parse@1.1.1. Драг-н-дроп PDF на Windows может багать — используй 📎.

Drag-and-drop архивов на Windows не работает
→ Известный баг Electron 32+. Используй кнопку 📎 вместо drag.

Проект исчез
→ Данные в localStorage браузера. Регулярно используй "Сохранить в файл" для бэкапа.
